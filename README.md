# soulforge

My workstation, soulforge, runs a custom Gentoo Linux setup. This repository is where I maintain my custom ebuilds, along with newer versions of software that are not yet available in the official Gentoo repositories.

My ebuilds are mostly focused on minimalism, performance, security, and reproducibility. I prefer keeping things clean and efficient, with minimal dependencies and precise configuration management. The goal is to have packages that are easy to maintain without adding unnecessary complexity to the system.

## About

This is my personal Gentoo Portage overlay. It contains the ebuilds, Manifests, and supporting files needed to maintain the packages I use. I do not distribute upstream binaries or personal system configuration through this repository.

While these ebuilds are maintained for my workstation, others are welcome to use them. I recommend reviewing the dependencies, USE flags, and package requirements before installing anything, since my configuration may differ from other Gentoo systems.
